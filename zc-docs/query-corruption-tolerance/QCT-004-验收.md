日期：2026-09-19。本轮 FE/协议测试通过，前置 QCT-002/003 的 BE 验收已通过。本记录不替代 QCT-006 的物理损坏验证。

## 实现

- 用户入口通过资格检查后下发可选开关；代码/产品模板此时均未默认开启。HTTP 入口由下一轮单独开放。
- `QueryCorruptionWarning` 将根结果统计中的 true 标记聚合为有界诊断 `SR_QUERY_PARTIAL_RESULT`，数字码 9000，附 query ID，不输出绝对文件路径。
- SELECT 最终 EOF 使用真实 Warning 数；已有 OK 路径沿用 `warningRows`。不改变用户结果列或结果集数量。
- 同会话 `SHOW WARNINGS` 支持 LIMIT/OFFSET，不在读取前清空诊断；`SHOW ERRORS` 不显示 Warning，也不清掉快照。下一条普通 SQL、解析/执行错误、COM_RESET_CONNECTION 清理。诊断与每次请求的 QueryState reset 分离。
- FE 转发增加 `TMasterOpResult` 可选诊断字段，只有 EOF/OK 接受并恢复，ERR 不被 Warning 覆盖。
