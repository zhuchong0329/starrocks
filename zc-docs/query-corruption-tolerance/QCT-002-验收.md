# QCT-002：独立扫描任务容错验收

日期：2026-09-19。独立扫描功能和本轮 5 项 BE 测试通过；真实 segment 字节损坏由 QCT-006 另行验证。

## 实现边界

- 仅独立 `OlapChunkSource` 的 `TabletReader::prepare/open` 和存储迭代器 `get_next` 接受明确 `Status::Corruption`，同时要求本查询开关已下发且未取消。
- 丢弃当前失败 Chunk，将该任务沿现有 EOF 路径结束；先前成功 Chunk 保留，兄弟任务不受共享停止影响。
- 本 BE 查询上下文记录单调诊断；本轮尚未接通客户端入口或跨 BE 传播。记录 query ID、tablet ID 和原始错误日志，不修复文件、不切换副本。
- 共享准备、非 Corruption、开关关闭和取消保持严格。未打开 Reader 不会继续读取；close 沿现有路径释放引用。
- 新增可选 `query_corruption_test` 目标，复用正常 BE_TEST 库和初始化。原完整 `starrocks_test` 保留，三个测试源仍在完整目标中。

```text

5 tests, 0 failures; exit code 0
```
