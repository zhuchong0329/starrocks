# QCT-005：HTTP SQL 验收记录

日期：2026-09-19。本轮 FE/HTTP 层测试通过；不以模拟 BE 代替 QCT-006 真实文件损坏验证。

## 实现

- 仅标准 NDJSON 接入，沿现有 EOS 返回末尾统计；同级字段为 `partial_result` 和 `warnings`，正常 ON 查询为 false/空数组。
- OFF、不适用路径保持原统计格式；raw 继续严格，不添加容错字段，不添加新的结果列/结果集。
- Warning 与 MySQL 使用同一诊断来源。无额外 `getNext`、RPC、完成屏障或后台诊断等待。
- 严格错误仍按基线在发送前返回错误、发送后断开，不把已发送 HTTP 200 当作成功，也不把严格错误转换成部分成功。
- 解析/执行错误清理会话旧诊断，避免 keep-alive 复用泄漏。

## 基线限制

4.0.11 的 HTTP raw 标志在同一 HTTP context 中存在只置 true 的行为；这是社区继承问题，本轮未混入修复。接入文档要求 raw 与标准模式分开连接，避免承诺未实现的模式切回。此限制不影响默认标准 NDJSON 的 keep-alive 验证。
